There are a lot of models and they change every few weeks. modelpick pulls in benchmark results, prices and what people are saying, then asks Claude to write one line on each model for me: what I’d use it for, and when I’d reach for something else.

It lives in the desktop bar. Click the icon and the panel opens in a floating terminal. Hover over it and you get the current picks.

What a refresh does

  1. Collect. Each source returns signals: a benchmark score, a discussion post, or just “this model exists”. The benchmarks are free, so they’re fetched for every model.
  2. Match names. Every source spells model names its own way. A matcher reconciles them, and you can pin an alias in the config when it gets one wrong.
  3. Write the takes. One call per model, in parallel. Each call also sees a short table of every model, so the takes compare them with each other rather than in a vacuum. A profile file says how I work, and it goes into every prompt.

Keeping it cheap

  • Only a refresh costs anything, and only when you press it. Opening the panel just reads a file.
  • Takes are only written for the providers you’re showing (Anthropic by default), and superseded models keep their old take without a new call.
  • The panel shows what each refresh cost, and asks first if one would write takes for more than 15 models.
  • It can run through claude -p instead of the API, so it counts against a plan instead of a bill.

Adding a source

A source is one Go file that implements a four-method interface and registers itself. It hands back signals and doesn’t care how the rest of the app uses them. The tests run a whole refresh against fakes of every source and of the Claude API.
