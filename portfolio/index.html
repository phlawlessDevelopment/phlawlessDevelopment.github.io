Mediator

A real-time chat app with a built-in AI facilitator. Invite-only rooms, live messaging, and a moderation pipeline that decides when a conversation is heating up, then posts one neutral, practical intervention and steps back.

The interesting part is the plumbing around the model: exactly-once mediation under concurrency, crash recovery that avoids double-billing, a persistent spend allowance, and revocation of live connections.

  • Java 25
  • Spring Boot 4.1
  • WebSocket / STOMP
  • SQLite + Flyway
  • OpenAI
  • Docker + Caddy
  • Oracle Cloud
