I build real-time web software and independent games, and I care about the engineering underneath both: correctness under concurrency and failure, small careful backends, and systems that can be tested.

The work here spans a Java and Spring Boot chat service with an AI facilitator, a Godot arcade game that runs in the browser with a fully synthesized soundtrack, and an Android auto-battler with deterministic combat and a serverless backend. Each project page has a write-up of the decisions behind it.
